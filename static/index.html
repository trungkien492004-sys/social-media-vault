Quản Lý File Cookies (Meta / TikTok)

Để trích xuất các trang cá nhân Facebook, bài viết hạn chế hoặc Instagram/Threads riêng tư, hãy tải file cookies.txt được xuất từ trình duyệt của bạn.

Cách lấy file cookies.txt:

  1. Cài tiện ích Chrome: Get cookies.txt LOCALLY
  2. Đăng nhập Facebook / Instagram trên trình duyệt Chrome
  3. Bấm vào biểu tượng tiện ích và chọn Export cookies.txt
  4. Tải file vừa xuất lên hệ thống bên dưới
